# 10 前端后台页面

## 今天要建立的理解

前端不是为了做得花哨，而是让面试官能看懂你的后端能力。一个清晰的后台页面可以帮助你演示登录、订单、库存、工单、日志这些流程。

## 你要重点考虑的问题

先考虑页面结构。你需要登录页、Dashboard、商品管理、库存管理、订单列表、工单列表、操作日志。页面不要太多，但每个页面要服务项目演示。

再考虑数据交互。前端要能带 token 请求后端，遇到 401 跳回登录，遇到 403 显示权限不足。列表页面要能筛选状态，详情页面要能看到关键字段。

还要考虑后台系统风格。不要做成营销网站。后台系统应该清楚、密集、稳定，重点是表格、筛选、状态标签、操作按钮。视觉上干净即可。

## 建议你查什么

推荐关键词：

- admin dashboard UI order management
- Vue axios JWT interceptor
- React admin table filter status
- enterprise admin UI layout
- permission based frontend routes

你可以找 Ant Design、Element Plus 这类组件库案例，学习后台页面常见布局。

## 怎么问 AI 更有效

可以问：

“我做的是企业后台系统，不是营销页面。请帮我设计前端页面信息架构，包括侧边栏、Dashboard 指标、列表筛选和详情页内容。”

也可以问：

“这是我的后端接口列表。请你帮我规划前端页面应该怎么调用这些接口，哪些页面需要筛选，哪些操作需要权限提示。”

## 你应该产出的东西

你需要完成一个能演示业务流程的前端：

- 登录
- Dashboard 指标
- 商品列表
- 库存管理
- 订单列表
- 工单列表
- 操作日志

不要求视觉非常高级，但要可用、清楚、不卡流程。

## 复盘问题

- 前端页面是否能帮我讲清楚项目？
- 哪些操作需要权限控制？
- Dashboard 指标是否来自真实后端数据？
- 面试演示时，我能不能在 3 分钟内跑完整个流程？

# OpsFlow 全栈项目学习文书目录

这套文书用于辅助你在两周左右完成一个中小型 Java 全栈项目：OpsFlow 订单库存与运营工单管理系统。

它不是一步一步照抄的教程，而是每天打开一份，提醒你今天要理解什么、查什么、做什么判断、如何把问题反馈给 AI 让它讲清楚。你可以把每份文书当成一个学习检查单。

## 使用方式

每次开始学习前，先读对应单元的“今天要建立的理解”。然后根据“你要重点考虑的问题”去查资料、写代码或画设计。遇到不懂的地方，不要只问“怎么写代码”，而是把你的现状、你的设计、你不确定的点发给 AI，让它帮你查缺补漏。

推荐每个单元结束后留下三样东西：

- 一段你自己的理解总结。
- 一份可以继续改的设计或代码。
- 三个你还没完全想明白的问题。

## 最重要的学习原则

不要把这个项目做成“功能列表”。你真正要积累的是对业务系统的理解：为什么要有订单状态，为什么库存不能随便扣，为什么要记录日志，为什么异常需要工单，为什么 Redis 和消息队列不是为了炫技，而是为了解决重复提交、异步处理、失败补偿和排查问题。

当你能把这些问题讲清楚时，这个项目才真正能服务你的实习申请。
